# Science after hours

Open this project in Studio. Choose View → Live quiz contest, select the address of the local Wi-Fi network, then Start new contest. Scan the join QR with two phones. The host opens a round, reveals the answer and shows individual and team standings. Open the project in Player to project the live questions through its assigned output warp. A single computer and separate browser profiles can rehearse all roles offline using 127.0.0.1. The sample includes ten rounds. Setup, backup and scoring appear in docs/LIVE-QUIZ.md.
