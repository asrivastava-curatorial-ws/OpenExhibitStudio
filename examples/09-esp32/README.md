# Light and motion

Open project.oes.json in Studio and press **▶ Try it** (F5), or open it in the standalone Player.

Use the three angle buttons in Test. In Hardware arm virtual outputs and pulse the button to see both output requests.

**Installation.** Classic ESP32 DevKit, WPA-protected isolated LAN, local Mosquitto, resistor-limited indicator and externally supplied low-torque hobby servo.

Use firmware/ExhibitESP32 and gateway/profiles/esp32.json. Flashing, output polarity and physical limits require bench commissioning.
