# Science after dark · live talk

An AhaSlides-style interactive talk: welcome slide, poll, word cloud, scored quiz questions,
rating scale, ranking poll, open-ended idea board, audience Q&A, a spinner-wheel prize draw and
a closing slide. Visitors join on their phones over the local network.

1. Open this project in Studio and go to **Live audience**.
2. Under **Who can join**, choose the local network (or *This computer only* to rehearse).
3. Press **Start session and present**. The presenter console opens in your browser; press **F**
   there to open the projector window and drag it to the projector (F11 for full screen).
4. Phones scan the QR code (or open the address shown) and pick a nickname.
5. Move through the slides with → / Space / a presentation clicker; ← goes back.

To change the slides, press **Edit slides**, then **Save slides into this exhibit** and save the
project. For a projection-mapped screen, open the project in the Player: the scene's live board
renders the current slide through that output's warp and blend.
