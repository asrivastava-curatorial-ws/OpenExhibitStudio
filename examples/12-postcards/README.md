# Visitor drawing wall

Open project.oes.json in Studio and choose **Test exhibit**, or open it in the standalone Player.

Launch the standalone player. Draw and type on output 1, then press Send to projection. Output 2 displays a snapshot. Clear the input without erasing the submitted drawing. A fresh visitor session clears both.

**Installation.** Two displays on one computer. The second may be a projector. This is the local projection delivery option.
