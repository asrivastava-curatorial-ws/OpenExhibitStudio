# Orbital atlas

Open project.oes.json in Studio and press **▶ Try it** (F5), or open it in the standalone Player.

Select Mars to read 686.98 Earth days. The rings are schematic. Relative orbital rates use sidereal years.

**Installation.** Single 16:9 touchscreen. No hardware gateway.



Planet data: https://nssdc.gsfc.nasa.gov/planetary/factsheet/
