# Electricity across time

Open project.oes.json in Studio and choose **Test exhibit**, or open it in the standalone Player.

In the Mapping workspace, select each of the three feeds. Adjacent feeds include a shared strip with complementary linear blend ramps.

**Installation.** Three projectors covering a horizontal screen. Assign the OS display indices in Output settings.

F2 reveals alignment grids on all outputs. A real overlap needs optical alignment and photometric tuning.

Historical background: https://www.nps.gov/articles/5-the-origins-of-hydroelectric-power.htm
