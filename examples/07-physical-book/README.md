# Rock pages under projection

Open project.oes.json in Studio and choose **Test exhibit**, or open it in the standalone Player.

Two independently corner-pinned outputs show the left and right parts of one logical spread. Inject page = 2 to open Sedimentary. Keyboard arrows and on-screen buttons are manual fallbacks.

**Installation.** Two outputs, a physical book, overhead webcam and printed markers 1–3, or an input adapter reporting page numbers.

Print print-markers.svg and run tools/vision.py book with a local gateway. For ArUco, generate PNGs with markers and select book --family aruco. Optical alignment and actual camera detection require bench testing.
