# Reef finder

Open project.oes.json in Studio and press **▶ Try it** (F5), or open it in the standalone Player.

In Hardware arm virtual outputs and inject dial = 70. Both output scenes show Sandstone and both indicator requests become 1. The standalone player opens the kiosk at 1280 × 720 and projector at 1024 × 768.

**Installation.** Touch display, projector and optional wired slider. For both real indicator channels configure the Uno and ESP32 profiles in one gateway.

Assign screen indices locally. The two indicators go through independent device endpoints.
