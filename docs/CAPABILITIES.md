# Release scope and remaining work

**0.2.0 is an engineering release.** The following table distinguishes working software paths, implementations that still need their target device or external dependency, and requested capabilities that remain open. An entry in the workspace switcher, pin catalogue or preset menu is not an acceptance result.

## Acceptance status

| Requested check | Evidence or next physical step |
| --- | --- |
| Save/reopen, export and preserve configuration | Automated round trips for all fourteen examples, assets and calibrated settings |
| Offline core | Local engine, packs, media, fonts and fixtures; smoke tests use local assets and loopback/virtual displays |
| Bidirectional Arduino | Uno, Nano and Mega firmware built with the AVR toolchain. POSIX pseudo-terminal and compiled common endpoint exercised. Real board/USB/bootloader test pending |
| ESP32 on isolated LAN | The ESP32 target sketch compiled. Authenticated Mosquitto/Paho exchange and broker-loss disarm passed with a compiled fixture. A real ESP32 and isolated Wi-Fi remain pending |
| Device loss and safe outputs | Simulated board disconnect, controller lease loss and endpoint watchdog tests; instrument the real output to verify physical response |
| One input to multiple screens and devices | Reef finder test updates two scene views and two virtual output requests; physical fan-out pending |
| Independent display resolutions | Linux X11/OpenGL test with two virtual display heads, two windows and distinct dimensions; physical connectors pending |
| Warp, blend, cylinder/sphere | 17 graphics render cases, independent Gray-code/optical checks, survey and holdout diagnostics. Physical projection remains unverified |
| Restart after power loss | Fresh runtime state, fail-safe boot code, rollback and atomic activation; hard power-cut test on a commissioned machine pending |
| Stability | 30-minute two-output headless run recorded 53,514 events. Multi-shift and multi-day hardware soaks remain pending |
| Install on clean operating systems | See the 0.2 test report for the clean Ubuntu userspace installation. Native Windows installation, full desktop commissioning and physical display wiring require a target machine |

The sample projects exercise the paths listed in their individual README files. Importing a device or output profile never establishes that its electrical wiring or optical calibration has been validated.
